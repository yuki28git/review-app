# ジャンル別IndexedDBページ

このアプリは、映画・アニメ・ドラマ・ゲームなどの作品データをジャンルごとにIndexedDBに保存し、Webブラウザ上で管理・検索・編集できるシングルページアプリケーションです。

https://yuki28git.github.io/review-app/

## 主な特徴

- **ジャンル切り替え**  
  映画・アニメ・ドラマ・ゲームの4ジャンルをタブで切り替え、それぞれ独立したデータベースとして管理できます。

- **フィルター検索**  
  - キーワード検索（作品名・キャラ名・声優名などに対応）
  - サブジャンル（例：「SF」「恋愛」など）
  - 年（公開・放送・発売年）
  - 声優・俳優名
  - 点数範囲（0〜100点の指定）

- **データの追加・編集・削除**  
  テーブル上で直接編集・追加でき、点数は常に最大100点までで制限されます。

- **詳細パネル表示・編集**  
  作品名クリックで詳細パネルが表示され、画像アップロード・あらすじ・感想・キャスト編集等が可能です。

- **ダイナミックな選択肢**  
  サブジャンル・年・声優などのフィルターメニューは、そのジャンル内の登録データから自動生成されます。

- **ソート**  
  各カラム（名前・ジャンル・日付・点数）でソートが可能です。

- **アクセシビリティ**  
  主要な操作はキーボードでも可能です（EnterやEscキー対応）。

## 使い方

1. **ジャンルを選択**  
   上部タブから「映画」「アニメ」「ドラマ」「ゲーム」のいずれかを選択。

2. **データ追加**  
   「追加」ボタンで新規データを入力し、「保存」で登録。

3. **編集/削除**  
   各行の「編集」ボタンで内容更新、「削除」ボタンで消去。

4. **詳細表示・編集**  
   作品名をクリックすると詳細パネルが開きます。  
   「編集」ボタンで詳細情報・画像・キャスト・感想などを編集可能。

5. **フィルター検索**  
   サイドバーからキーワード入力や各種フィルター適用で絞り込み。  
   「適用」で反映、「リセット」で初期化。

6. **点数入力制限**  
   追加・編集時の点数は0～100のみ有効です。

## 技術仕様

- **フロントエンド**  
  - HTML/CSS/JavaScript（バニラJSのみ、フレームワーク不使用）
  - レスポンシブデザイン
  - アクセシビリティ対応

- **データストレージ**  
  - [IndexedDB](https://developer.mozilla.org/ja/docs/Web/API/IndexedDB_API)  
    各ジャンルごとに独立したObjectStoreを自動作成
  - [Cloud Firestore](https://firebase.google.com/docs/firestore)  
    Googleログイン中は `users/{uid}/items` に同期保存され、同じアカウントであればPC/iPhone間で同じデータを参照

- **画像管理**  
  - 画像はBase64としてIndexedDB内に保存されます（ファイル選択でアップロード可能）

## 注意事項

- **端末間同期について**
  - 同じGoogleアカウントでログインすると、初回ログイン時にクラウド同期が走ります。
  - クラウドに既存データがある場合は、そのデータが端末側へ取り込まれます。
  - クラウドが空で端末側にデータがある場合は、端末側データをクラウドへ保存します。

- **Firestore セキュリティルール（必須）**
  Firebase Console の Firestore ルールを、少なくとも以下のように設定してください。

```text
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/items/{itemId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```

- ログインしていない場合、データはそのブラウザ内（IndexedDB）にのみ保存されます。
- ログインしている場合、データはFirestoreにも同期されるため、同じGoogleアカウントなら他端末でも共有されます。
- IndexedDBの仕様上、一部古いブラウザでは正常に動作しない場合があります。
- 画像アップロードのファイルサイズが大きいと、保存や表示が遅くなる場合があります。
